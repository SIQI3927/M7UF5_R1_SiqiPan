M07UF5R1_VR Game.

Se suponía que debía crear el juego con mis compañeros de equipo, pero a menudo faltaban o casi no hacían nada, así que decidí completar esta práctica solo.

Aunque intenté encontrar tutoriales para crear un juego de realidad virtual, me resultó demasiado difícil. Hice todo lo posible, pero no pude solucionar los problemas ni los errores. Más tarde, Xavi me permitió usar la parte del juego del proyecto para completar esta práctica.
Toda la escena fue construida por mí, y la parte de desarrollo del juego fue tomada de lo que Santiago ya había completado.

Al enviar el enlace, adjunté una grabación de pantalla de demostración para una vista previa fácil, pero definitivamente hay una diferencia entre el simulador y el uso real de las gafas VR.
